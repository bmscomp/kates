Bootstrap address — this is the string that belongs in the mirror-maker2 chart:

  mirrors:
    - source:
        alias: legacy
        bootstrapServers: {{ include "legacy-kafka.bootstrapAddress" . }}
        kafkaVersion: "{{ .Values.kafka.version }}"
{{- if .Values.listeners.sasl.enabled }}
        authentication:
          type: plain
          username: {{ (index .Values.listeners.sasl.users 0).username }}
          secretName: <a Secret you create in the MM2 namespace>
{{- else }}
        authentication:
          type: ""          # PLAINTEXT — no credentials
{{- end }}

`kafkaVersion` is not decoration: the mirror-maker2 chart compares it against
the KIP-896 floor (Kafka 2.1) that 4.x clients enforce, and refuses to render
below it rather than letting the connector fail at runtime.
