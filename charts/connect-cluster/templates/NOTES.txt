────────────────────────────────────────────
  Getting Started
────────────────────────────────────────────

1. Wait for KafkaConnect to become ready:

  kubectl wait kafkaconnect/{{ include "connect-cluster.fullname" . }} \
    --for=condition=Ready -n {{ include "connect-cluster.namespace" . }} --timeout=300s

2. Check worker pods:

  kubectl get pods -n {{ include "connect-cluster.namespace" . }} \
    -l strimzi.io/name={{ include "connect-cluster.fullname" . }}-connect \
    -o custom-columns=NAME:.metadata.name,READY:.status.containerStatuses[0].ready,NODE:.spec.nodeName

3. Run Helm tests:

  helm test {{ .Release.Name }} -n {{ include "connect-cluster.namespace" . }}
